# Nhiệm vụ của Raspberry Pi

## Hệ điều hành và mạng
- DietPi, headless.
- SSH/Tailscale SSH.
- Không Dashboard, không hotspot.

## Âm thanh
- Thu âm Bluetooth.
- Gửi WAV/M4A lên Mac.
- Nhận và phát MP3.

## Camera
- Chụp JPG theo chế độ nhận diện, OCR hoặc dẫn đường.
- Không xử lý AI nặng.

## Giao tiếp
- HTTP qua Tailscale.
- Bearer Token.
- Timeout, retry và xử lý mất mạng.
- Không giữ Gemini API key.
