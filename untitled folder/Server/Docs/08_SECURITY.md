# Bảo mật

- Bearer Token cho endpoint xử lý.
- Token lưu trong .env trên Pi và Mac.
- Gemini API key chỉ lưu trên Mac.
- Chỉ giao tiếp qua Tailscale.
- Không public server trực tiếp ra Internet.
- Giới hạn kích thước request và Content-Type.
- Xóa file tạm sau xử lý.
- Không ghi bí mật vào log hoặc Git.
